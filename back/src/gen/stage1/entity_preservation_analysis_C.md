**Overall assessment:** The manufacturer and product class mappings preserve row identity using their primary-key attributes, and `schema:brand` is a schema-grounded object-property path. However, the `schema:url` mapping creates an IRI directly from an attribute without a relational path to a pivot entity. Under the stated formal assumptions, the complete mapping set therefore **does not fully satisfy entity preservation** unless `schema:url` is treated as a datatype property or changed to an FK-backed entity relationship.
